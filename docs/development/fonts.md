# Шрифты

Проект использует два семейства, оба лежат локально в `public/fonts/` и раздаются с
домена проекта. Внешних запросов (Google Fonts, CDN) нет.

| Роль | Семейство | Токен | Где применяется |
| --- | --- | --- | --- |
| Интерфейс | **Inter** | `--font-ui` | навигация, кнопки, таблицы, метаданные, формы |
| Редакционный текст | **Source Serif 4** | `--font-serif` | `.prose`, заголовки `h1–h6`, текст статей |
| Код | системный моноширинный | `--font-mono` | `code`, `pre`, технические значения |

`--font-mono` не поставляется файлом: это стек `ui-monospace, SFMono-Regular, 'SF Mono',
Menlo, Consolas, 'Liberation Mono', monospace`. Для кода в энциклопедии этого достаточно,
а лишний файл весил бы больше, чем экономит.

## Файлы

```
public/fonts/
├── LICENSE.md                           текст лицензии и upstream-ссылки
├── inter-latin.woff2                    48 256 B
├── inter-cyrillic.woff2                 18 748 B
├── source-serif-4-latin.woff2          122 360 B
├── source-serif-4-cyrillic.woff2        93 440 B
├── source-serif-4-italic-latin.woff2   130 188 B
└── source-serif-4-italic-cyrillic.woff2 90 356 B
```

Итого ~503 КБ на шесть файлов. Это вариативные начертания с диапазоном веса 400–700:
один файл покрывает regular, medium, semibold и bold, поэтому вместо восьми статических
файлов на семейство лежит один (плюс подмножества и курсив).

Подмножества: `latin` и `cyrillic`. Греческий, вьетнамский и другие наборы не включены —
контент проекта на английском, а русский нужен для интерфейса и будущих переводов.

## Как подключены

`app/client/styles/_fonts.scss` содержит шесть `@font-face` и подключается из
`_base.scss` (`@use 'fonts'`), а `main.scss` импортирует `base`. То есть шрифты входят в
общий CSS-бандл и не требуют отдельного `<link>` в layout.

Каждое правило:

```scss
@font-face {
	font-family: 'Inter';
	font-style: normal;
	font-weight: 400 700;
	font-display: swap;
	src: url('/fonts/inter-latin.woff2') format('woff2');
	unicode-range: U+0000-00FF, U+0131, ..., U+FFFD;
}
```

- `font-weight: 400 700` — диапазон для вариативного шрифта;
- `font-display: swap` — текст виден сразу системным шрифтом, затем подменяется; это
  лучше, чем невидимый текст на медленной сети;
- `unicode-range` — браузер скачивает только те подмножества, которые реально нужны
  странице. Английская статья не тянет cyrillic-файлы, русская — тянет оба;
- пути абсолютные (`/fonts/...`), потому что файлы лежат в docroot, а не в сборке.

`preload` в layout нет: при двух семействах и двух подмножествах предзагрузка всех
файлов конкурировала бы с CSS. Если понадобится, добавьте `<link rel="preload"
as="font" type="font/woff2" crossorigin>` только для одного файла — обычно
`source-serif-4-latin.woff2`, потому что он самый большой и нужен для первого экрана
статьи.

## Лицензия

Inter и Source Serif 4 распространяются под **SIL Open Font License 1.1**. Она разрешает
использовать, изменять и распространять шрифты, в том числе в составе сайта, при
условии сохранения уведомления о лицензии и нераздельной продажи самих шрифтов.

Условия и upstream-ссылки зафиксированы в `public/fonts/LICENSE.md`:

- Inter — [github.com/rsms/inter](https://github.com/rsms/inter);
- Source Serif 4 и Source Serif 4 Italic —
  [github.com/adobe-fonts/source-serif](https://github.com/adobe-fonts/source-serif).

Файлы взяты из upstream-релизов в виде woff2-подмножеств (latin + cyrillic, вариативный
вес 400–700). Полный текст OFL 1.1 —
[openfontlicense.org](https://openfontlicense.org/open-font-license-official-text/).
Зарезервированные имена «Inter» и «Source Serif» принадлежат авторам: если вы
модифицируете файлы и распространяете их отдельно, переименуйте семейство.

`LICENSE.md` лежит рядом со шрифтами, поэтому требование OFL о сопровождении шрифтов
текстом лицензии выполнено. Не удаляйте его при «чистке» `public/`.

## Почему локально

- **Приватность.** Запрос к `fonts.gstatic.com` сообщает третьей стороне IP и User-Agent
  каждого посетителя. Для энциклопедии о здоровье это лишнее.
- **Скорость.** Нет дополнительного DNS-запроса, TLS-рукопожатия и ожидания чужого
  сервера; шрифты едут с тем же HTTP/2-соединением, что и CSS.
- **Предсказуемость.** Google Fonts обновляет файлы; локальная копия не изменится
  незаметно и не сломает метрики.
- **Работа без сети.** Сайт полностью функционален в офлайне и в закрытом контуре.
- **Проще CSP.** Нет `font-src` на внешний домен.

## Как заменить или добавить шрифт

1. Скачайте woff2-подмножества нужного семейства (Google Fonts отдаёт woff2 по
   `unicode-range`; альтернатива — `@fontsource/*` в npm).
2. Положите файлы в `public/fonts/` по схеме `<family>-<subset>.woff2` и
   `<family>-italic-<subset>.woff2` — так имена остаются предсказуемыми.
3. Добавьте `@font-face` в `_fonts.scss` с тем же `unicode-range`, что у соседних
   файлов того же подмножества, и `font-display: swap`.
4. Поменяйте токен в `_tokens.scss` (`--font-ui` или `--font-serif`), сохранив фолбэк-стек.
5. Проверьте лицензию: не все семейства под OFL; некоторые требуют покупки веб-лицензии.
6. Соберите (`bun run build` или дождитесь HMR) и проверьте страницу.

Добавлять новый шрифт «для красоты» не стоит: два семейства — это уже бюджет ~500 КБ, а
третье почти всегда ухудшает чтение и скорость.

## Как проверить загрузку

**Браузер.** DevTools → Network → фильтр `Font`. Должны быть только запросы к
`/fonts/*.woff2` со статусом 200 (или 304), без обращений к `fonts.googleapis.com` и
`fonts.gstatic.com`. В Elements → Computed для `body` — `Inter`, для `.prose` —
`Source Serif 4`.

**Командная строка:**

```bash
curl -sSI https://longevypedia.localhost/fonts/inter-latin.woff2 | head -5
# HTTP/2 200
# content-type: font/woff2

curl -sS https://longevypedia.localhost/ | grep -c "fonts.gstatic.com"   # 0
```

**Сборка.** В CSS-бандле должны быть `@font-face` с путями `/fonts/...`:

```bash
grep -o "/fonts/[a-z0-9.-]*woff2" public/build/assets/main-*.css | sort -u
```

**Кириллица.** Откройте страницу с русским текстом (например, `/ui-kit` — там русские
подписи) и убедитесь, что загрузились `*-cyrillic.woff2`. Если нет — проверьте
`unicode-range`: браузер выбирает подмножество по символам на странице, а не по `lang`.

## Ограничения

- Нет автоматического `preload` и `font-size-adjust`; при смене шрифта метрики могут
  сдвинуть первый экран (CLS). `font-display: swap` смягчает, но не убирает сдвиг.
- Нет подмножеств для других языков: при добавлении локали с латиницей всё работает, для
  греческого/арабского/китайского нужны новые файлы и новые `@font-face`.
- Нет версионирования имён файлов: при замене шрифта браузерный кеш может отдать старую
  копию. Сбрасывайте кеш или переименуйте файл.
